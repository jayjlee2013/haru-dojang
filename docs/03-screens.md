# 03. 화면 설계

모바일 우선 (기준 폭 375px), 데스크톱에서는 중앙 정렬된 단일 컬럼. 화면은 총 7개 + 오버레이 3종. 하단 탭 없이 **도장(홈) 중심 + 좌우 스와이프/버튼 이동** — 화면 수 자체를 미니멀하게 유지.

## 내비게이션 구조

```
온보딩 (최초 1회)
   ↓
도장 (홈) ←→ 일지          # 홈 우상단 책 아이콘
   ↓
보스전 화면 (보스 관문 활성 시 홈이 이 모드로 전환)
승급 오버레이 (보스 클리어 시)
관문 만들기 (자유 슬롯 도달 시)
설정 (홈 우상단 톱니)
```

## 1. 온보딩 (최초 실행)

| 단계 | 내용 |
|------|------|
| 1 | 프롤로그 텍스트가 한 줄씩 표시 (탭하면 다음 줄) — 02문서의 프롤로그 전문 |
| 2 | "일지를 펼친다" 버튼 → 흰띠 1관문 소개 카드 |
| 3 | "수련 시작" 버튼 → 도장(홈)으로. 끝. |

- 이름 입력, 목표 설문, 알림 허용 요청 **전부 없음**. 30초 안에 첫 화면 도달.
- 하루 경계 안내 문구 한 줄만: "새벽 4시까지는 오늘로 칩니다."

## 2. 도장 (홈) — 핵심 화면

첫 목업(Fable 5 세션에서 제작) 레이아웃 그대로. 구성 요소:

### 상단 바
- 좌: 현재 띠 표시 (띠 색상 막대 + "노란띠 3단") + 총 도장 수
- 우: 일지 아이콘 (새 조각 있으면 점 표시), 설정 아이콘

### 현재 관문 카드 (화면의 주인공)
- "지금 도전 중인 관문 · N번째" 라벨
- 관문 이름 (큰 글씨) + 조건 ("7일 안에 5번이면 도장 획득")
- 진행 세그먼트 바: 목표 횟수만큼 칸, 채운 만큼 색칠. **남은 기한** 표시 ("오늘 포함 4일 남음")
- **[오늘 도장 찍기]** 버튼 — 하루 1회. 찍으면:
  - 도장 찍히는 애니메이션 (스탬프가 쾅 — 0.5초, 햅틱)
  - 버튼이 "오늘 수련 완료" 상태로 변경
  - 이 순간이 앱의 전부다. 반드시 기분 좋게.

### 수련 경로 (세로 리스트)
- 클리어 관문: 붉은 인주색 도장 원 (살짝 기울어진 각도 — 손으로 찍은 느낌) + 이름 + "클리어"
- 현재 관문: 강조 표시
- 다음 관문 1개만 잠금 상태로 노출, 그 뒤는 "···" (미리 다 보여주지 않음 — 궁금증 유지)
- 경로 끝: 보스전 노드 (방패 아이콘, "모든 관문을 깨면 도전 가능")

### 상태 변형
| 상태 | 홈 표시 |
|------|--------|
| 오늘 이미 찍음 | 버튼 비활성 아님 — "오늘 수련 완료" 확인 상태로 표시 |
| 관문 기한 임박 (남은 일수 = 남은 필요 횟수) | 카드에 조용한 경고 "이제부터 매일 찍어야 깰 수 있어요" |
| 관문 실패 (기한 초과) | 재수련 카드: "괜찮다. 다시." — 관장 톤 한 줄 + [재수련 시작] 버튼. 벌점·빨간색 없음 |
| 관문 클리어 순간 | 도장 획득 연출 → 일지 조각 카드 자동 표시 → 다음 관문 소개 |

## 3. 일지 화면

- 세로 스크롤 책 형태. 조각들이 장(章) 순서대로.
- 열린 조각: 전문 표시 (세리프체, 여백 넉넉히 — 읽는 맛)
- 잠긴 조각: 「▨▨▨」 + "N번째 관문을 깨면 열린다"
- 상단: "일지 12/25장" 수집 카운터
- 무한 수련 모드부터: 하단에 "2권 — 나의 기록" 섹션, [오늘 기록 남기기] 입력 (선택)

## 4. 보스전 모드 (홈 화면 변형)

보스 관문이 활성화되면 홈의 현재 관문 카드가 보스전 카드로 바뀐다:

- 카드 테두리·배경이 살짝 어두운 톤 (검보라) — 유일하게 분위기가 바뀌는 순간
- "승급 심사 — 노란띠 보스전" + 조건 "3일 연속"
- 진행 표시: 큰 원 3개 (연속 실패 시 원이 전부 리셋되는 게 보임 — 긴장감)
- 연속이 끊기면: "심사는 다시 열린다. 언제든." — 즉시 재도전 가능, 대기 없음

## 5. 승급 오버레이 (보스 클리어 시)

- 전체 화면: 이전 띠 색 → 새 띠 색으로 전환되는 애니메이션 (색상 전환만, 폭죽 없음 — 미니멀)
- "노란띠 수여" + 보스 일지 조각 표시
- 새로 해금된 것 안내 (예: "자유 관문이 열렸다")

## 6. 관문 만들기 (자유 슬롯 / 무한 모드)

- 필드 3개뿐: 관문 이름, 몇 번 (기본 5), 며칠 안에 (기본 7)
- 유효성: 이름 1~30자, 횟수 1~14, 기간 ≥ 횟수, 기간 ≤ 21
- 안내 문구: "작게 정할수록 좋은 관문이다. — 관장"
- 프리셋 제안 3개 (탭하면 채워짐): "10분 책 읽기", "설거지 바로 하기", "저녁 산책"

## 7. 설정

- 하루 경계 시각 (기본 04:00)
- 데이터 내보내기 (JSON 다운로드) / 가져오기
- 전체 초기화 (2단계 확인: "정말로 도장을 닫습니까?")
- 앱 정보

## 디자인 언어

- **색**: 배경 순백/근백. 잉크색 텍스트. 포인트는 인주(印朱) 레드 단 하나 — 도장·버튼에만. 띠 색상(흰/노랑/초록/검정)은 띠 표시와 승급 연출에만.
- **타이포**: UI는 산세리프, 일지 본문만 세리프 — "일지는 다른 사람의 목소리"라는 신호.
- **모션**: 도장 찍기 스탬프 애니메이션 하나에만 공을 들인다. 나머지는 페이드 정도.
- **일러스트 없음**: 아이콘은 라인 아이콘, 도장 원은 CSS로.
- **다크 모드**: 시스템 설정 따름. 인주색은 동일 유지.
