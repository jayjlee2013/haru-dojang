# 01. 컨셉 정의

## 한 줄 정의

**하루도장** — 물려받은 낡은 생활무술 도장에서 하루 하나의 관문을 깨며 수련 일지의 비밀을 열어가는, 혼자만의 미니멀 도장깨기 앱.

## 문제 정의

기존 습관앱이 실패하는 이유:

1. **결정 피로**: 습관 10개를 동시에 관리 → "오늘 뭐부터 하지"라는 고민이 또 하나의 일이 됨
2. **할 일 목록화**: 앱을 열면 미완료 항목이 쌓여 있음 → 죄책감 유발 장치가 됨
3. **연속 기록의 폭력성**: 하루 놓치면 100일 기록이 0으로 → 그날 앱을 지움

## 해법: 도장깨기 구조

포켓몬 체육관처럼 **한 번에 딱 하나의 관문만** 존재한다. 깨야 다음이 열린다.

- 오늘 할 일은 언제나 하나 → 결정 피로 제로
- 첫 관문은 "물 한 컵 마시기" 수준으로 우스울 만큼 쉬움 → 초반 성공 경험이 연료
- 이미 딴 도장(스탬프)은 절대 뺏기지 않음 → 앱을 열 때마다 쌓인 것이 보임

## 이름의 중의성

"도장"의 세 가지 의미가 컨셉을 하나로 묶는다:

| 의미 | 앱에서의 구현 |
|------|--------------|
| 도장(道場) — 무술 수련장 | 세계관: 물려받은 낡은 도장, 띠 승급 |
| 도장(圖章) — 찍는 스탬프 | 핵심 인터랙션: "오늘 도장 찍기" |
| 도장깨기 — 순차 격파 | 진행 구조: 관문을 하나씩 깸 |

## 핵심 설계 원칙 3가지

1. **선택지를 없앤다** — 오늘 할 일은 단 하나. 홈 화면에 목록이 아니라 "지금 도전 중인 관문" 하나만 크게 보인다.
2. **어이없을 만큼 쉽게 시작한다** — 흰띠 첫 관문은 실패가 불가능한 수준. 난이도는 띠가 올라가며 아주 천천히 상승.
3. **수집욕과 정체성을 건드린다** — "레벨 37"이 아니라 "초록띠 2단". 도장이 하나씩 늘어나는 화면 자체가 보상.

## 확정된 4대 결정 (2026-07-06)

### 1. 사용 대상: 나 혼자용
- 계정/로그인 없음. 모든 데이터는 로컬 저장.
- 확장 가능성(가족 공유, 공개 배포)은 설계에서 배제하지는 않되, 구현하지 않는다.

### 2. 세계관: 미니멀 + 스토리 모드
- UI는 도장판·진행바·경로만. 캐릭터 일러스트, 컷신 없음.
- 스토리는 **관장의 수련 일지** 텍스트 조각(총 25편, 각 1~4문장)으로만 존재.
- 관문을 깰 때마다 일지 한 장이 열린다. 스토리는 보상이지 의무가 아니다 — 안 읽어도 게임 진행에 지장 없음.
- 서사: 낡은 도장을 물려받은 나, 떠난 관장이 남긴 일지, 그리고 마지막 장의 반전. (전문은 02-content-design.md)

### 3. 관문 설계: 시간축으로 배치된 3단계 자유도
- **흰띠**: 기본 코스만 (튜토리얼 — 선택 피로 제로)
- **노란띠~**: 코스 중간에 "자유 관문" 슬롯 해금 (노랑 1개 → 초록 2개 → 검정 3개). 해금 자체가 보상.
- **검은띠 클리어 후**: 무한 수련 모드 — 모든 관문을 스스로 만들고, 일지의 다음 장을 직접 쓴다.

### 4. 실패 처리: 누적 방식
- 평상시 관문: **"N일 안에 M번"** (예: 7일 안에 5번). 하루 놓쳐도 무너지지 않는다.
- **승급 보스전만 3일 연속** 요구 — 긴장감은 보스전에만. 게임의 완급 조절과 동일한 원리.
- 관문 실패(기간 내 미달성) 시: 벌점 없음. 해당 관문만 "재수련"으로 처음부터. 이미 모은 도장·띠는 유지.

## 하지 않을 것 (Non-goals)

- 소셜 기능, 랭킹, 친구 비교
- 광고, 인앱 결제
- 서버, 계정, 클라우드 동기화 (JSON 내보내기/가져오기로 백업 대체)
- 푸시 알림 (M5에서 PWA 알림만 검토, 핵심 루프는 알림 없이 성립해야 함)
- 통계 대시보드 (그래프·차트 없음 — 도장 수집 화면이 곧 통계)
