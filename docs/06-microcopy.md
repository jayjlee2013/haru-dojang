# 06. 마이크로카피 전집 — 관장의 목소리

> 앱 안의 모든 짧은 문구. **원본은 이 문서이며, 코드로 옮길 때 임의 수정·추가 금지** (02문서와 동일 규칙).
> 톤 규칙: 관장의 말은 짧고 담백하고 무뚝뚝하지만 온기가 있다. 느낌표·이모지·"~요"체 금지. 시스템 문구(설정·오류)는 관장이 아니라 앱이 말하는 것 — 건조하고 정확하게.

## 1. 도장 찍은 직후 반응 (랜덤 풀 — 하나씩 표시)

1. 좋다.
2. 오늘 몫을 했다.
3. 쌓인다.
4. 그거면 된다.
5. 어제의 너보다 한 번 더.
6. 수련은 소리가 나지 않는다. 이렇게 쌓일 뿐.
7. 도장은 거짓말을 하지 않는다.
8. 작다고 웃지 마라. 산도 돌 하나부터다.
9. 됐다. 가서 네 하루를 살아라.
10. 물 흐르듯. 내일 또.

- 표시 위치: 스탬프 애니메이션 직후, 버튼 아래 1.5초 페이드.
- 랜덤이되 직전 것과 중복 금지.

## 2. 오늘 이미 찍음 상태

- 버튼 영역: `오늘 수련 완료`
- 보조 문구: `내일 새벽 4시에 새 하루가 열린다`

## 3. 기한 임박 경고 (남은 일수 = 남은 필요 횟수)

> 이제부터는 하루도 빠질 수 없다.

- 카드 안 한 줄, 색은 잉크색 유지 (빨간색 금지 — 경고도 조용하게).

## 4. 관문 실패 → 재수련 카드 (랜덤 풀)

1. 괜찮다. 다시.
2. 넘어진 것까지가 수련이다.
3. 실패한 관문은 있어도, 끝난 수련은 없다.
4. 이 관문이 유난히 미끄러웠을 뿐이다. 다시 잡아라.
5. 돌아온 것만으로 반은 됐다.
6. 기록은 지워졌지만, 몸은 기억한다.

- 버튼: `재수련 시작`
- 재수련 2회차부터는 보조 문구 추가: `N번째 도전. 관장은 횟수를 세지 않는다.`

## 5. 보스전

| 상황 | 문구 |
|------|------|
| 보스전 진입 안내 | `승급 심사다. 사흘. 변명은 접어두고.` |
| 최종 보스전(검은띠) 진입 | `마지막 심사다. 닷새. 네가 고른 것들로 치른다.` |
| 심사 중 하루 성공 | `하루. 흔들리지 마라.` / `이틀. 반환점이다.` (일차별 고정) |
| 연속 끊김 | `심사는 다시 열린다. 언제든.` |
| 재도전 시작 | `숨 고르고. 다시 사흘.` |

## 6. 승급 오버레이

| 승급 | 문구 (일지 조각과 별도로, 띠를 매는 순간의 한 줄) |
|------|------|
| → 노란띠 | `노란 띠를 맨다. 이제 시작이다.` |
| → 초록띠 | `초록 띠를 맨다. 몸이 기억하기 시작했다.` |
| → 검은띠 | `검은 띠를 맨다. 이제 혼자서도 갈 수 있다.` |
| → 관장 취임 | (문구 없음 — B-최종보스 일지 조각이 전부를 말한다. 침묵이 연출.) |

## 7. 관문 클리어 (보스 아닌 일반 관문)

- 도장 획득 연출 중: `관문 돌파` + 관문 이름
- 일지 조각 카드로 넘어가는 버튼: `일지가 한 장 열렸다`

## 8. 자유 관문 만들기

- 화면 제목: `나만의 관문`
- 안내: `작게 정할수록 좋은 관문이다. — 관장`
- 필드 라벨: `무엇을` / `몇 번` / `며칠 안에`
- 유효성 오류 (시스템 톤):
  - 이름 없음: `관문의 이름이 필요하다`
  - 기간 < 횟수: `횟수보다 기간이 짧다. 하루에 한 번씩이 최대다`
- 프리셋 12개 (탭하면 채워짐, 기본 7일 안에 5번):
  1. 10분 책 읽기
  2. 설거지 바로 하기
  3. 저녁 산책
  4. 아침 커피는 앉아서 마시기
  5. 하루 한 번 하늘 보기
  6. 영양제 챙겨 먹기
  7. 5분 눈 감고 앉아 있기
  8. 미루던 연락 하나 하기
  9. 점심은 책상 밖에서
  10. 자기 전 5분 정리
  11. 물 여섯 컵
  12. 계단으로 다니기

## 9. 무한 수련 모드

- 홈 상단 표기: `관장 수련 N일째` (띠 표기 대체)
- 관문 없음(빈 상태): `도장이 비어 있다. 다음 관문은 관장이 정한다 — 그게 너다.` + 버튼 `관문 만들기`
- 일지 2권 입력 안내: `오늘의 장을 남기겠는가. 짧아도 된다.` / 입력 placeholder: `수련 N일. `
- 기록 저장 직후: `일지가 두꺼워진다.`

## 10. 일지 화면

- 상단 카운터: `일지 N/25장`
- 잠긴 장: `▨▨▨` + `다음 관문을 깨면 열린다`
- 새 조각 알림 점 tooltip: `읽지 않은 장이 있다`

## 11. 온보딩

- 프롤로그는 02문서 전문 사용. 진행 버튼: `다음` → `일지를 펼친다` → `수련 시작`
- 하루 경계 안내 (마지막 화면 하단, 작게): `새벽 4시까지는 오늘로 칩니다`

## 12. 설정·시스템 문구 (앱 톤 — 관장 아님)

| 항목 | 문구 |
|------|------|
| 하루 경계 설정 | `하루의 시작 시각` / 보조: `이 시각 전까지는 전날로 칩니다` |
| 내보내기 | `데이터 내보내기 (JSON)` |
| 가져오기 | `데이터 가져오기` |
| 가져오기 실패 | `파일을 읽을 수 없습니다. 하루도장에서 내보낸 파일인지 확인해 주세요` |
| 가져오기 확인 | `지금 데이터를 이 파일로 바꿉니다. 계속할까요?` / `바꾸기` / `취소` |
| 전체 초기화 1단계 | `도장을 닫습니까?` / 보조: `모든 도장과 일지가 사라집니다` |
| 전체 초기화 2단계 | `정말로 닫습니까? 되돌릴 수 없습니다` / 버튼: `닫는다` / `남는다` |
| 시계 되돌림 감지 | `기기의 날짜가 마지막 수련보다 과거입니다. 날짜를 확인해 주세요` |
| 매일 알림 걸기 | `매일 알림 걸기` / 보조: `앱은 알림을 보내지 않습니다. 고른 시각으로 폰 캘린더에 반복 일정을 하나 넣어 드립니다` / 버튼: `캘린더에 넣기` |
| 캘린더 일정 내용 (앱 밖) | 제목: `하루도장` / 설명: `오늘의 도장을 찍을 시간입니다.` |

> **알림에 대한 입장 (2026-08-11 결정).** 앱이 사용자를 쫓아다니는 푸시 알림은 넣지 않는다 —
> 이건 원래 의도적으로 뺀 것이고 카피에도 "알림 없음"이 들어가 있다. 다만 *사용자가 직접 걸어둔*
> 알림은 다르다고 보고, 기본 꺼짐 · 본인이 시각을 골라 캘린더에 넣는 방식만 허용한다.
> 기술적으로도 이 방법뿐이다: 크롬의 Notification Triggers API는 개발이 중단됐고,
> 서버 없이 웹에서 알림을 예약할 방법이 없다. 12번 표의 문구도 "앱은 알림을 보내지 않습니다"로
> 시작해 이 약속을 UI에서 다시 확인시킨다.

## 13. 금지 목록 (구현 시 절대 넣지 말 것)

- 이모지, 느낌표, "축하합니다/잘했어요/화이팅" 류의 응원
- 빨간색 경고, 실패 카운트 노출, "연속 기록이 끊겼습니다" 같은 상실 프레임
- 푸시성 문구 ("돌아오세요", "보고 싶어요")
- 관장 톤과 시스템 톤의 혼용 (관장은 반말 단문, 시스템은 존댓말 설명문)
